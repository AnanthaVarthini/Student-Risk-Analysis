# Student Risk Analysis

A machine learning project that analyses student academic performance and identifies students who may be at risk.

## About

This project explores how machine learning can be used to understand student performance based on factors like attendance, midterm marks, final marks and assignment scores.

Students are classified into three categories:

- Low Risk
- Medium Risk
- High Risk

## What I did

- Performed data cleaning and preprocessing.
- Explored the dataset using visualisations.
- Created an Academic Performance Index.
- Built a student risk classification system.
- Trained and compared different ML models.
- Generated recommendations based on student risk levels.

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest

## Tools & Libraries

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Evaluation Metrics

Accuracy, Precision, Recall, F1-score and Confusion Matrix.
